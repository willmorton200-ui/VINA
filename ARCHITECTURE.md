# Архитектура проекта VINA (РСХБ.Цифра)

## Обзор пайплайна

Система VINA — это end-to-end решение для распознавания винных этикеток с цилиндрических поверхностей с последующим поиском по базе векторных эмбеддингов.

Проект состоит из двух основных подсистем:

1. **CV Пайплайн (Cylindrical Dewarping & OCR)** - `pipeline/dewarp_engine.py`
2. **Поисковый движок (SigLIP + FAISS)** - `pipeline/search_engine.py` & `pipeline/catalog.py`

---

## 1. CV Пайплайн (Развертка и распознавание)

Для устранения цилиндрических искажений бутылки используется многоэтапный подход:

1. **Локализация и Сегментация**:
   - `YOLOv8-seg` находит бутылку на изображении.
   - `SAM (Segment Anything)` (ViT-H) уточняет маску.
   - Выделяется наибольшая связная компонента маски.

2. **Извлечение геометрических признаков**:
   - Находятся 4 физических угла этикетки.
   - Вычисляются боковые линии (образующие цилиндра).

3. **Оптимизация сетки (Coon's Patch)**:
   - Строится трансфинитная сетка Кунса, учитывающая кривизну.

4. **Обратная деформация**:
   - Используется Thin Plate Spline (TPS) трансформация.
   - Ресемплинг изображения с фильтром Lanczos-4.

5. **Распознавание (OCR)**:
   - Используется `EasyOCR` (GPU) для извлечения текста.

---

## 2. Поисковый движок (Поиск по каталогу)

Для сопоставления загруженного фото с каталогом «Своё Вино» (2000+ позиций) используется нейросеть **SigLIP 2**.

1. **Подготовка базы (Индексация)**:
   - `WineCatalog` читает `strapi_output0709.csv` и сопоставляет slug с фотографиями из папки `uploads`.
   - `WineSearchEngine` прогоняет все изображения через модель `ViT-B-16-SigLIP2-384`.
   - Полученные векторы L2-нормализуются и добавляются в индекс `FAISS (IndexFlatIP)` (Inner Product эквивалентен Cosine Similarity).
   - Индекс сохраняется на диск (`models/siglip2_index.faiss`) вместе с маппингом slug-ов.

2. **Поиск (Inference)**:
   - Сервер получает изображение на `/v1/eval/predict`.
   - Изображение конвертируется в вектор с помощью SigLIP.
   - FAISS находит топ-N ближайших векторов.
   - Сервер возвращает slug наиболее похожего вина.

## 3. API и Интерфейс

Бэкенд реализован на **FastAPI** (`app.py`), сервер работает на порту `8080`.

### Ключевые эндпоинты

- `POST /v1/eval/predict` — SLA < 3 сек, используется для скрипта оценки. Возвращает `{"slug": "..."}`.
- `GET /api/wine/{slug}` — Возвращает метаданные вина (название, сорт, регион и т.д.).
- `GET /api/image/{slug}` — Раздает оригинальные фотографии вин.
- `GET /scanner` — Мобильный интерфейс сканера на HTML/CSS/JS.

### Мобильный интерфейс (`static/scanner.html`)

- Адаптивный mobile-first дизайн ("Своё Вино").
- Позволяет загрузить фото или сделать снимок.
- Отображает карточку вина и предлагает аналоги ("Цифровой сомелье").
